# vungoctruong
DEV CODE NGỌC TRƯỜNG - VNT Tricks Website

Static website ready for deployment on [Vercel](https://vercel.com).

## Deployment on Vercel

1. Import this repository in Vercel.
2. Settings:
   - **Framework Preset**: Other
   - **Root Directory**: ./
   - **Build Command**: None
   - **Output Directory**: ./

## Local Development

Run the local server:
`ash
python server.py
`
Open [http://localhost:3000](http://localhost:3000) in your browser.
